# MAC Filter Classifier

이 프로그램은 `data.json`에 저장된 필터와 패턴을 읽어서,  
각 패턴이 `Cross` 또는 `X` 중 어느 쪽에 더 가까운지 MAC(Multiply-Accumulate) 점수로 판정합니다.

---

## 1. 실행 방법

### 1-1. 준비 파일
아래 파일들이 같은 폴더에 있어야 합니다.

- `main.py`
- `data.json`

### 1-2. 실행
터미널에서 아래 명령을 실행합니다.

```bash
python main.py
```

### 1-3. 메뉴 선택
실행 후 다음 메뉴가 표시됩니다.

```text
Mini NPU Simulator
1) 사용자 입력(3×3)
2) data.json 분석
입력 방식 선택 (1/2):
```

- `1` : 사용자가 직접 3×3 필터와 패턴을 입력
- `2` : `data.json`을 읽어서 자동 분석

---

## 2. 프로그램 동작 방식

`data.json` 분석 모드에서는 다음 순서로 동작합니다.

1. `filters`에서 패턴 크기에 맞는 `cross`, `x` 필터를 찾음
2. `patterns`에서 테스트 케이스를 읽음
3. 패턴과 각 필터의 MAC 점수 계산
4. 더 높은 점수의 라벨을 예측
5. `expected` 값과 비교하여 PASS/FAIL 판정
6. 결과를 `result.json`으로 저장

---

## 3. 판정 기준

판정은 다음 규칙으로 수행됩니다.

- `Cross` 점수 > `X` 점수 → 예측 = `Cross`
- `X` 점수 > `Cross` 점수 → 예측 = `X`
- 두 점수가 거의 같으면 → `UNDECIDED`

정답 라벨은 `expected` 값을 기준으로 정규화합니다.

- `"+"` → `Cross`
- `"x"` → `X`

---

## 4. 실패 원인 분석

실패가 발생하는 이유는 단순한 코드 오류라기보다,  
**필터 가중치와 판정 정책의 영향**일 가능성이 큽니다.

### 대표적인 실패 원인

#### 1) 가중치가 비대칭적임
- `size_13`, `size_25`처럼 큰 필터에는 중심부에 큰 가중치가 들어 있습니다.
- 패턴이 중심과 정확히 맞지 않으면 점수 차이가 달라질 수 있습니다.

#### 2) 두 필터 점수가 근접함
- `Cross`와 `X` 점수가 비슷하면 판정이 흔들릴 수 있습니다.
- 특히 `compare_labels()`는 점수가 거의 같으면 `UNDECIDED`를 반환합니다.

#### 3) 패턴은 같아 보여도 수치 차이가 있음
- 패턴과 필터의 모양이 비슷해도 실제 값이 다르면 점수 차이가 생깁니다.
- 예를 들어 `0.1`, `0.3`, `4.9`, `7.5` 같은 가중치는 판정에 큰 영향을 줄 수 있습니다.

#### 4) 데이터셋 자체의 설계
- 이 문제는 단순한 형태 분류처럼 보여도, 실제로는 가중치 기반 비교입니다.
- 따라서 구조가 비슷한 패턴끼리도 결과가 달라질 수 있습니다.

---

## 5. 데이터 기준 해석

현재 `data.json`을 보면 다음과 같은 특징이 있습니다.

- `size_5`는 비교적 단순한 구조
- `size_13`은 중심 가중치가 강함
- `size_25`는 대칭 구조가 커서 점수 차이가 미세할 수 있음

즉, 일부 케이스는 안정적으로 판정되지만,  
일부 케이스는 점수 차이가 작아 실패가 발생할 수 있습니다.

---

## 6. 시간 복잡도 분석

### 6-1. MAC 연산 1회 복잡도
`n × n` 행렬의 모든 원소를 한 번씩 곱해서 더하므로:

- **시간 복잡도: O(N²)**
- **공간 복잡도: O(N²)**

여기서 `N`은 행렬 한 변의 길이입니다.

---

### 6-2. 한 케이스 처리 복잡도
한 패턴 케이스에 대해 다음 연산을 수행합니다.

- Cross 필터와 MAC 계산: `O(N²)`
- X 필터와 MAC 계산: `O(N²)`
- 비교 및 출력: `O(1)`

따라서 한 케이스 전체는:

- **O(N²)**

---

### 6-3. 전체 데이터셋 복잡도
패턴 케이스 수를 `M`이라고 하면, 전체 복잡도는:

- **O(M × N²)**

즉, 케이스 수가 늘어나거나 행렬 크기가 커질수록 실행 시간이 증가합니다.

---

### 6-4. 성능 측정 방식
프로그램은 `benchmark_mac_2d()` 함수를 사용하여 MAC 연산 시간을 측정합니다.

- 반복 횟수: `BENCH_REPEAT = 10`
- 출력값: 평균 실행 시간(ms), 연산 횟수(`N²`)

이 방식은 한 번의 실행 시간보다 더 안정적인 평균 성능을 확인하는 데 도움이 됩니다.

## 8. 정리

이 프로그램은 `data.json`에 있는 패턴과 필터를 바탕으로  
MAC 점수를 계산하여 `Cross` / `X`를 판정하는 구조입니다.

핵심 포인트는 다음과 같습니다.

- JSON 구조에 맞춰 패턴과 필터를 읽음
- MAC 점수로 판정 수행
- 결과를 콘솔과 `result.json`에 저장
- 시간 복잡도는 `O(M × N²)` 형태
