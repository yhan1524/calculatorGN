
# 🚀 Mini NPU Simulator

`Mini NPU Simulator`는 입력된 패턴과 필터 간의 **MAC(Multiply-Accumulate)** 연산을 수행하여, 패턴이 어떤 형태(`Cross` 또는 `X`)에 더 가까운지 판정하고 연산 성능을 측정하는 학습용 시뮬레이터입니다.

---

## 1. 주요 기능

- **MAC 연산 기반 판정**: 패턴과 필터의 원소별 곱의 합을 계산하여 유사도 측정
- **사용자 모드 (3x3)**: 직접 필터와 패턴을 입력하여 즉석에서 결과 확인
- **JSON 분석 모드**: `data.json`에 정의된 대량의 테스트 케이스 자동 분석 및 성능 측정
- **라벨 정규화**: 다양한 형태의 입력 라벨(`+`, `cross`, `x`, `diag` 등)을 표준 라벨로 통일
- **성능 벤치마크**: 각 연산의 평균 실행 시간(ms)과 총 연산 횟수(N²) 측정

## 2. 실행 방법

### 2-1. 준비 사항
- Python 3.x 설치
- `main.py`와 `data.json` 파일이 동일한 경로에 위치

### 2-2. 실행 명령
```bash
python main.py
```

### 2-3. 메뉴 선택
1. **사용자 입력 3x3**: 직접 3x3 행렬 3개(필터 A, B, 패턴)를 입력하여 비교
2. **성능 분석**: `data.json`을 읽어 크기별(5x5, 13x13 등) 필터와 패턴을 자동 매칭 및 분석
0. **종료**: 프로그램 종료

---

## 3. 핵심 로직 설명

### 💡 MAC (Multiply-Accumulate) Score
패턴($P$)과 필터($F$)의 동일한 위치의 원소를 곱하여 모두 더한 값입니다.
$$Score = \sum_{i=0}^{N-1} \sum_{j=0}^{N-1} (P_{i,j} \times F_{i,j})$$

### ⚖️ 판정 기준 및 EPS
- **Cross 점수 > X 점수**: `Cross`로 판정
- **X 점수 > Cross 점수**: `X`로 판정
- **부동소수점 오차 처리**: 두 점수의 차이가 `EPS(1e-9)`보다 작으면 `UNDECIDED`(판정 불가)로 처리하여 수치적 안정성을 확보합니다.

### 🔄 라벨 정규화 (Normalization)
다양한 데이터 소스의 라벨을 아래와 같이 통일하여 비교합니다.
- `+`, `cross`, `c`, `plus` → **cross**
- `x`, `diag` → **x**

## 4. `data.json` 데이터 구조

프로그램은 `data.json`에서 아래와 같은 구조를 기대합니다.

```json
{
  "filters": {
    "size_5": {
      "cross": [[...], [...], [...], [...], [...]],
      "x": [[...], [...], [...], [...], [...]]
    }
  },
  "patterns": [
    {
      "name": "sample_1",
      "size": 5,
      "input": [[...]],
      "expected": "cross"
    }
  ]
}
```
*※ `input` 키 외에도 `matrix`, `data`, `pattern` 키를 자동으로 인식합니다.*

### 5-1. 사용자 입력
1) A와 패턴이 동일
```bash

 - 필터 A 점수: 5.0000
 - 필터 B 점수: 1.0000
 - 평균 연산 시간: 0.001915 ms
 - 총 연산 횟수: 9 (N^2)
 - 판정: A
==================================================
```
2) B와 패턴이 동일
```bash
==================================================
 - 필터 A 점수: 1.0000
 - 필터 B 점수: 5.0000
 - 평균 연산 시간: 0.002010 ms
 - 총 연산 횟수: 9 (N^2)
 - 판정: B
==================================================
```
3) A,B의 값이 같은 경우
```bash
==================================================
 - 필터 A 점수: 5.0000
 - 필터 B 점수: 5.0000
 - 판정: 판정 불가(|A-B| < 1e-9)
==================================================
```

## 6. 예외 처리 및 주의사항

- **행렬 크기 불일치**: 패턴과 필터의 크기가 다를 경우 `ValueError`를 발생시키고 해당 케이스를 건너뜁니다.
- **정사각 행렬**: 모든 입력 데이터는 가로와 세로 길이가 같은 정사각 행렬이어야 합니다.

- **사용자 입력**: 숫자 이외의 값을 입력하거나 지정된 개수(3개)와 다르게 입력할 경우 재입력을 요구합니다.
```bash
2행 (3개, 공백 구분): 0 1 
입력 오류: 3개의 숫자를 입력해야 합니다.. 처음부터 다시 입력해주세요.
```
